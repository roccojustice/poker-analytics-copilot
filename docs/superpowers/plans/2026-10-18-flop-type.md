# Flop Type Filter (M7 #6, part 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A multi-select Flop control filters a Spotlight result (distribution, facing split, hands) to the hands whose flop is one of the user's 8 flop types, and the hand list shows each hand's type.

**Architecture:** A pure `board_types.py` classifies a flop. `db.run_spot_query` also returns `chs.card_1..3`; `spotlight.run_spot` tags every match with `flop_type`, drops unselected types before labels / distribution / split / hand details, and merges `flop_type` into the hands. The SQL `WHERE` and `get_hand_details` are unchanged. `api.py` and the page pass `flop_types` through.

**Tech Stack:** Python 3, FastAPI, pandas, SQLAlchemy/psycopg2 over PT4 Postgres, pytest, vanilla JS.

**Spec:** `docs/superpowers/specs/2026-10-18-flop-type-design.md`

## Global Constraints

- Canonical names, in page order: `BLL`, `Low`, `2BWL`, `Low paired`, `High paired`, `A high`, `Monotone`, `3BW`. Defined once in `board_types.FLOP_TYPES` (a tuple in that order).
- Rules (broadway = A K Q J T; plain = not paired and not monotone): Monotone first; paired (pair or trips) → `Low paired` if the paired rank is 2–8, else `High paired`; plain with 3 broadway → `3BW`; exactly 2 → `2BWL`; exactly 1 and it is A → `A high`; exactly 1 and it is K/Q/J → `BLL`; otherwise → `Low`.
- Exact counts over the 22,100 three-card flops: Low paired 2,044 · High paired 1,752 · 3BW 600 · 2BWL 4,800 · A high 1,680 · BLL 5,040 · Low 5,040 · Monotone 1,144.
- `get_hand_details` is not modified (the frozen NL path calls it for hands with card id 0).
- Empty `flop_types` = Any. Unknown name → `SpotInputError` naming it (→ 400). Dedupe, keep order.
- Inline comments: one line max. Strict TDD: watch each test fail for the expected reason.
- Branch `m7-flop-type`. Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Run tests with `venv/Scripts/python -m pytest ...` (Bash); `-m db` runs the Postgres tests.

## Review Focus

1. **A flop filter that leaves zero hands** must give zero distribution rows, four zero split rows and skip the detail query. Pinned in Task 2.
2. **Flop filter + facing split** (`vs B?`, `["BLL"]`): split rows are computed over BLL hands only. Pinned in Task 2.
3. **A misspelled or lowercase type** (`"bll"`) from the API must be a 400 that names it, not an empty result. Pinned in Tasks 2 and 3.
4. **Duplicate types** (`["BLL", "BLL"]`) show once in the filter text and filter the same as one. Pinned in Task 2.
5. **The frozen NL path** (`POST /query`) keeps working: no change to `get_hand_details`. Pinned by the existing `tests/test_db.py` / `test_api.py` suites staying green in every task.
