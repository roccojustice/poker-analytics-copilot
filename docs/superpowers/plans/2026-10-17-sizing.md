# Bet Sizing (M7 #5) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An optional per-street size suffix (`s`/`m`/`l`/`o`) in the Spotlight Line filters on the size of that street's bet, and a Hero-bet decision splits `B` into one distribution row per size under an overall `B` row.

**Architecture:** A new `sizing.py` holds the bucket registry and the street-bet SQL expression. `line_parser` strips the suffix and stores it on `StreetSpec.size`. `spot_sql` turns each size into two bound conditions and, for `B`/`X` decisions, returns a measured expression that labels bets `Bs`/`Bm`/`Bl`/`Bo`. `spotlight` builds the split distribution and the interpreted-filter text. `index.html` indents the sub-rows and matches hands by parent.

**Tech Stack:** Python 3, FastAPI, pandas, SQLAlchemy/psycopg2 over PT4 Postgres, pytest, vanilla JS.

**Spec:** `docs/superpowers/specs/2026-10-17-sizing-design.md`

## Global Constraints

- Buckets (fraction of pot at street start, lower inclusive, upper exclusive): S `[0, 0.45)`, M `[0.45, 0.70)`, L `[0.70, 1.05)`, O `[1.05, ∞)`.
- Street's bet = `chps.amt_<s>_bet_made + chps.amt_<s>_bet_facing` (Hero's row only); pot = `chs.amt_pot_<s>`.
- Compare as `bet >= lo * pot AND bet < hi * pot`, with `lo`/`hi` bound as `Decimal`, never interpolated, never floats.
- A Line without suffixes must produce exactly today's SQL conditions and results (the `db` oracle stays green).
- Inline comments: one line max (`feedback_comment_discipline`).
- Strict TDD: see each test fail for the expected reason before implementing.
- Work on branch `m7-sizing`. Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Run tests with the venv: `venv/Scripts/python -m pytest ...` (Bash) — `pytest` skips `db` tests by default; `-m db` runs them.

## Review Focus

1. **A bet exactly on a boundary** (e.g. 0.45 into 1.00) must land in M, not S. Float params would make `0.45 * pot` drift; pinned in Task 2 by asserting the bound params are `Decimal`.
2. **Lowercase / spaced input** (`vs bs ?`) must equal `vs Bs?`. Pinned in Task 1.
3. **A villain shove bigger than Hero's stack** is sized by what Hero can call, and the bucket agrees with the % shown in the hand table. Pinned in Task 5 (bucket vs `f_size` agreement over real hands).
4. **A suffix where no bet exists** (`- Xs-?`, `vs Xs?`, `- s?`) must be a clear 400, not an empty result. Pinned in Task 1.
5. **Clicking the overall `B` row shows every bet; a zero-hand result shows all six B/X rows at 0.** Pinned in Task 3 (zero rows) and Task 4 (parent match, checked in the browser).

```python
from decimal import Decimal

# suffix -> (name, lo, hi) as fractions of the pot at street start; lo inclusive, hi exclusive
SIZE_BUCKETS = {
    "S": ("small", Decimal("0"), Decimal("0.45")),
    "M": ("medium", Decimal("0.45"), Decimal("0.70")),
    "L": ("large", Decimal("0.70"), Decimal("1.05")),
    "O": ("overbet", Decimal("1.05"), None),
}


def street_bet_sql(street):
    """The street's only bet from Hero's row: Hero's bet, else the bet Hero faced (SCHEMA_NOTES)."""
    return f"(chps.amt_{street}_bet_made + chps.amt_{street}_bet_facing)"


def size_text(size):
    name, lo, hi = SIZE_BUCKETS[size]
    pct = lambda x: f"{int(x * 100)}%"
    if hi is None:
        return f"{name} (≥{pct(lo)})"
    if lo == 0:
        return f"{name} (<{pct(hi)})"
    return f"{name} ({pct(lo)}–{pct(hi)})"
```

```python
def _size_conditions(street, size, params):
    _, lo, hi = SIZE_BUCKETS[size]
    bet, pot = street_bet_sql(street), f"chs.amt_pot_{street}"
    sql = f" AND {bet} >= %(size_{street}_lo)s * {pot}"
    params[f"size_{street}_lo"] = lo
    if hi is not None:
        sql += f" AND {bet} < %(size_{street}_hi)s * {pot}"
        params[f"size_{street}_hi"] = hi
    return sql


def _sized_bet_label(street, params):
    bet, pot = street_bet_sql(street), f"chs.amt_pot_{street}"
    whens = []
    for key, (_, _, hi) in SIZE_BUCKETS.items():
        if hi is None:
            open_label = f"B{key.lower()}"
            continue
        whens.append(f"WHEN {bet} < %(bucket_{key})s * {pot} THEN 'B{key.lower()}'")
        params[f"bucket_{key}"] = hi
    return f"CASE {' '.join(whens)} ELSE '{open_label}' END"
```

def _row(action, label, name, hands, total, parent=None):
    row = {"action": action, "label": label, "name": name, "hands": hands,
           "pct": round(hands / total * 100, 1) if total else 0.0}
    if parent:
        row["parent"] = parent
    return row


def _distribution(labels, measured, prefix):
    counts = labels.value_counts()
    total = int(counts.sum())
    rows = []
    for action in measured:
        label = prefix + action
        if action != "B":
            rows.append(_row(action, label, ACTION_NAMES[action], int(counts.get(label, 0)), total))
            continue
        subs = [(f"B{k.lower()}", f"Bet {name}") for k, (name, _, _) in SIZE_BUCKETS.items()]
        sub_counts = [int(counts.get(prefix + sub, 0)) for sub, _ in subs]
        rows.append(_row("B", label, "Bet", sum(sub_counts), total))
        rows += [_row(sub, prefix + sub, name, n, total, parent=label)
                 for (sub, name), n in zip(subs, sub_counts)]

import math
import pytest
from spotlight import run_spot

pytestmark = pytest.mark.db

RANGES = {"s": (0, 45), "m": (45, 70), "l": (70, 105), "o": (105, math.inf)}
EPS = 1e-9  # f_size is a float; the SQL compares exact numerics


def hand_ids(line, role="pfc", position="oop"):
    return set(run_spot("2bp", position, role, line)["hands"]["id_hand"])


def test_size_suffixes_partition_the_unsized_line():
    full = hand_ids("vs B?")
    parts = [hand_ids(f"vs B{k}?") for k in RANGES]
    assert all(parts)
    assert set().union(*parts) == full
    assert sum(len(p) for p in parts) == len(full)


@pytest.mark.parametrize("k", RANGES)
def test_faced_bet_bucket_agrees_with_the_hand_table_size(k):
    lo, hi = RANGES[k]
    sizes = run_spot("2bp", "oop", "pfc", f"vs B{k}?")["hands"]["f_size"]
    assert ((sizes >= lo - EPS) & (sizes < hi + EPS)).all()


def test_hero_bet_label_agrees_with_the_hand_table_size():
    result = run_spot("2bp", "ip", "pfr", "- ?")
    bets = result["hands"][result["hands"]["measured_action"].str.startswith("B")]
    assert len(bets) > 0
    for label, size in zip(bets["measured_action"], bets["f_size"]):
        lo, hi = RANGES[label[1]]
        assert lo - EPS <= size < hi + EPS, (label, size)
    overall = next(r for r in result["distribution"] if r["label"] == "B")
    assert overall["hands"] == len(bets)
